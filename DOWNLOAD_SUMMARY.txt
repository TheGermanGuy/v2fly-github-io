TROUBLESHOOTING
===============

Q: "ModuleNotFoundError: No module named 'kivy'"
A: pip install kivy>=2.1

Q: "ModuleNotFoundError: No module named 'm3uScan_v21_5'"
A: Ensure m3uScan_v21_5.py is in same directory

Q: GUI opens but black screen
A: Check logs: cat ~/.m3uscan/logs/m3uscan_*.log

Q: Status checks timeout
A: Increase timeout in Settings (GUI) or NETWORK_TIMEOUT (code)

Q: App freezes/crashes
A: Enable Low-Memory Mode or reduce Batch Size

Q: Can't install dependencies
A: pip install --upgrade pip setuptools wheel
   pip install kivy --prefer-binary
