📋 USAGE INSTRUCTIONS
══════════════════════════════════════════════════════════════════════════════

1. Enable Auto-Worker (Default)
   WORKERS_AUTO = True
   The function automatically determines optimal workers

2. View Worker Selection
   In terminal, you'll see:
   "Auto-determined: 10 workers (RAM (512MB available))"

3. Disable Auto-Worker (Manual)
   cfg.workers_auto = False
   cfg.workers = 8  # Use fixed value

4. Understanding the Limiting Factor
   • "CPU (4 cores)": CPU is the bottleneck
   • "RAM (512MB)": Memory is the bottleneck
   • "Device maximum": Hardware limit reached
   • "Device minimum": Ensuring minimum parallelism
