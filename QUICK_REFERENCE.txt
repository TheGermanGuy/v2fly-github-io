⏱️ TIMEOUTS & PERFORMANCE
================================================================================

Parameter          Default  Mobile   Effect
─────────────────────────────────────────────────────────────────
WORKERS            8        4        Parallel requests
TIMEOUT            10s      10s      Request timeout
PRECHECK_TIMEOUT   3.5s     3.5s     TCP test
TASK_TIMEOUT_MULT  2.5      2.0      Hard limit (25s/20s)
CHECKPOINT_EVERY   50       30       Save progress
CF_JITTER_BASE     3.0      2.0      CloudFlare retry

For slow connections: Increase TIMEOUT to 15-20s
For many errors: Increase PRECHECK_TIMEOUT to 5s
For stability: Reduce WORKERS to 4-6

================================================================================
🚨 TROUBLESHOOTING
================================================================================

Error: "No module named 'aiohttp'"
  Fix: pip install aiohttp

Error: "No module named 'tkinter'" (GUI)
  Fix: sudo apt install python3-tk  (Ubuntu)
       brew install python-tk       (macOS)

Error: "link_ledger.json: Permission denied"
  Fix: chmod 644 link_ledger.json
       or run in different folder

Error: GUI won't start
  Fix: Verify tkinter: python3 -c "import tkinter; print('OK')"
       Use CLI instead if GUI fails

Error: CloudFlare blocks (too many 429s)
  Fix: Increase CF_JITTER_BASE to 5.0
       Set CF_MAX_RETRIES to 1-3 (if possible)
